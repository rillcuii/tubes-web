# InvenTech - Sistem Inventaris Toko (Frontend Skeleton)

Aplikasi kerangka tampilan (*Frontend Skeleton*) untuk manajemen inventaris barang toko yang dibuat menggunakan **HTML5** dan **Tailwind CSS**. Proyek ini merupakan bagian dari tugas perkuliahan aplikasi *fullstack* dari awal hingga pekan ke-14.

---

## Stack / Teknologi
* **Markup:** HTML5
* **Styling Framework:** Tailwind CSS (v3 via CDN)

---

## Alasan Pemilihan Tailwind CSS
Pemilihan **Tailwind CSS** didasari oleh karakteristik aplikasi inventaris *InvenTech* yang membutuhkan tampilan terstruktur dan responsif:
1. **Utility-First Approach:** Memungkinkan penulisan *styling* yang presisi pada kartu statistik, tabel data, dan form langsung di elemen HTML tanpa perlu membuat file CSS eksternal secara terpisah.
2. **Kemudahan Grid & Flexbox:** Fitur bawaan Tailwind seperti `grid-cols-1`, `sm:grid-cols-2`, dan `lg:grid-cols-3` sangat memudahkan pembuatan tata letak dashboard yang responsif di berbagai ukuran layar.
3. **Efisiensi Pengembangan Frontend:** Mempercepat proses pembuatan prototipe dan komponen antarmuka yang bersih sebelum dihubungkan ke backend database.

---

## Fitur & Komponen Halaman
1. **Navigasi Responsif (Navbar):** Dilengkapi dengan tombol *hamburger* yang akan muncul saat dibuka pada layar HP/Mobile.
2. **Dashboard Utama:** Menggunakan tata letak *Grid Layout* untuk menampilkan rangkuman statistik data inventaris.
3. **Daftar Data (Tabel):** Menampilkan tabel inventaris barang yang responsif dengan *scroll* horizontal pada layar kecil.
4. **Form Input Data:** Form sederhana untuk input barang baru.
